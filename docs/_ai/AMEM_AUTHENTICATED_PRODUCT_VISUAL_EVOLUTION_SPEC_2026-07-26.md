## 1. Jornadas

| Elemento | Spec |
|----------|------|
| Lista | Progresso claro (N/7) sem gamification infantil |
| Etapa | 1 foco: texto + CTA concluir/continuar |
| Erro 5xx | Mensagem humana + retry · sem stack |
